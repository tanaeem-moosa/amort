# Asymptotic Complexity Bridges for Greedy Algorithms

## Theorems
- `isBigO_intervalSchedulingWork_mul_size`: Interval scheduling is $O(n \cdot \text{size } n)$.
- `isBigO_huffmanConstructionWork_mul_size`: Huffman coding is $O(n \cdot \text{size } n)$.
- `isBigO_bfprt_linear_atTop`: Median-of-Medians is $O(n)$ under `Filter.atTop`.
