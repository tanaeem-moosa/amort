# Asymptotic Complexity Bridges for Number Theoretic Algorithms

## Theorems
- `isBigO_modExpMulSteps_size`: Fast modular exponentiation multiplications are $O(\text{size } b)$.
- `isBigO_modExpMulSteps_log`: Fast modular exponentiation multiplications are $O(\log b)$.
- `isBigO_extGCDSteps_comap_min_atTop`: Extended GCD division steps are $O(\text{size}(\min a\ b))$.
- `isBigO_sieveWork_mul_size`: Sieve of Eratosthenes work is $O(n \cdot \text{size } n)$.
